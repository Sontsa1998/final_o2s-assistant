## 35. Contacter l’Assistance : trouver votre numéro de contrat O2S

Pour contacter l’Assistance O2S, il est préférable de connaître votre numéro de contrat ; celui-ci est disponible à 2 endroits : Dans le module Administration. Si vous avez accès à l’administration (via votre menu personnel > Administration ), l’encart Nom et coordonnées de la société affiche un numéro qui est votre numéro de contrat commençant par Cx suivi d’un nombre.
