## 384. Nouvelle agrégation en attente

Nouvelle agrégation en attente


1. Connaissance


1.1 : Description

L'attente des premiers fichiers d'agrégation pour un utilisateur O2S peut parfois être longue, que ce soit parce que le paramétrage de cette agrégation dans son O2S est techniquement erroné ou bien parce que la source d'agrégation tarde à fournir les fichiers attendus. Cette attente au-delà d'un délai raisonnable est pénalisante pour l'utilisateur.
Fournir à l'utilisateur une explication claise des raisons pour lesquelles l'agrégation des données pour son code apporteur nouvellement paramétré est toujours en attente. Guider l'utilisateur à travers les étapes de vérification qu'il peut effectuer lui-même, et qui sont essentielles car de nombreuses sources d'agrégation disposent de procédures spécifiques. Si le problème persiste après les vérifications initiales, proposer de soumettre le cas à l'équipe technique. Demander l'autorisation de faire suivre la conversation à l'assistance pour éviter une double saisie. Collecter les informations nécessaires pour l'escalade à une équipe technique.

1.2 Méthode


Hypothèse : Des problèmes peuvent bloquer l'agrégation, et donc l'activation d'un nouveau paramétrage. Les incidents en cours sont signalés sur cette page : https://o2s-help.harvest.fr/meteo-agregation/
Action : Vérifier les incidents en cours liés à la source d'agrégation. Un incident peut bloquer l'agrégation et donc l'activation d'un nouveau paramétrage réalisé par l'utilisateur.

Hypothèse : Après le paramétrage par l'utilisateur, des actions peuvent être attendues de sa part pour qu'Harvest reçoive des données à agréger.
Action : Vérifier dans la documentation liée à la source d'agrégation si l'arrivée des fichiers d'agrégation est conditionné à une action de la part d'un utilisateur.

Hypothèse : La source d'agrégation peut mettre plusieurs jours à mettre en place l'envoi de nouveaux fichiers à Harvest. Si le nouveau paramétrage réalisé par l'utilisateur a moins de 5 jours, il est encore trop tôt pour relancer le fournisseur.
Action : Vérifier dans la documentation liée à la source d'agrégation si l'arrivée des fichiers d'agrégation est conditionné à une action de la part d'un utilisateur. Si ce n'est pas le cas et que le paramétrage d'agrégation a moins de 5 jours, inviter l'utilisateur à patienter.

2. Glossaire


Terme : Code apporteur
Synonymes : Code partenaire

Terme : Source d'agrégation
Synonymes : Dépositaire, fournisseur, teneur de compte, assureur
