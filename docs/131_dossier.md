## 131. Dossier

Pour accéder au dossier d’un contact, il vous suffit de double-cliquer sur son nom dans la liste de vos contacts (https://o2s-help.harvest.fr/liste-des-contacts/) , ou dans le module de recherche. Vous arrivez alors dans l’onglet Général du contact. Pour accéder aux autres onglets thématiques, cliquez sur Tout parcourir en haut à droite. Général Tout parcourir Dossier constitue la rubrique dans laquelle vous devez renseigner toutes les informations sur vos contacts. Elle est constituée de plusieurs onglets. Dossier Il est important de renseigner ces pages avec le maximum d’informations sinon vous devrez le faire avant de pouvoir utiliser certaines fonctionnalités d’O2S. Conjoint/ Partenaire/ Concubin Cet onglet est seulement visible si la situation familiale de votre client est ‘Marié(e)’, Union libre’ ou ‘Pacsé’. Il vous permet de renseigner les informations concernant le conjoint, partenaire ou le concubin de votre client. Vous pouvez le créer en sélectionnant un contact de votre base ou bien en créer un en renseignant les champs de saisie. Relations. Relations Cet onglet vous permet de renseigner d’une part des liens de filiation ascendante et descendante, et d’autre part, de créer des relations avec les personnes, sociétés, et organisations de votre choix. Vous pouvez les créer en sélectionnant des contacts de votre base ou bien en créer de nouveaux en renseignant les champs de saisie. Pour créer un enfant, cliquez sur Ajouter ou bien sur Choisir pour sélectionner l’enfant dans la liste de vos contacts. Ensuite, saisissez les informations requises dans la page qui apparaît. Puis cliquez sur OK . Cliquez sur Enregistrer pour valider les modifications effectuées.
