## 362. Informations sur l'agrégation de  Suravenir

# Suravenir

## À savoir
Afin que votre demande d'agrégation puisse etre validée et fonctionnelle, vous devez contacter Suravenir pour leur demander l'envoi des fichiers vers O2S.

Votre code apporteur apporteur est composé de 11 chiffres commençant par 003.


Assurez-vous d'avoir bien complété et signé la lettre d'autorisation.
Les mouvements peuvent être agrégés sur une profondeur de 3 mois glissants
