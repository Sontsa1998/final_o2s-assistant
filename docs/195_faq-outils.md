Le profil d’investisseur n’y est pas repris. Le module Requêtes interroge l’ensemble de la base, y compris les profils d’investisseur et documents de connaissance client réalisés en dehors de la conformité. Les résultats sont donc souvent plus nombreux. Le filtre « Décédé » Les blocs du module Pilotage incluent les personnes décédées. Dans le module Requêtes , le filtre Décédé est paramétré par défaut sur Non , ce qui exclut automatiquement ces contacts du résultat. Les filtres cumulatifs Les blocs de Pilotage disposent uniquement de filtres sommaires (conseiller, type de contact…). L’onglet Requêtes propose de nombreux filtres qui se cumulent, permettant une recherche très spécifique mais pouvant réduire le nombre de résultats affichés. Combien de temps après une demande d’agrégation, les données peuvent être importées via les alertes Nouveaux clients et Nouveaux contacts ?.    Si les données sont disponibles, vos alertes techniques « Nouveaux clients/contacts » interviendront dans les 5 jours ouvrés suivant la réception de votre demande. Dans le cas contraire, nous attirons votre attention sur les différentes démarches qui peuvent être nécessaires pour la mise à disposition des données par le fournisseur (lettre d’autorisation, demande de format penelop, contact partenaire, etc…). Ces données sont détaillées dans le fichier Recueil de données (https://o2s-help.harvest.fr/agreger-des-nouveaux-partenaires/) . Compte tenu de ces opérations, le délai, pour l’apparition de vos alertes « Nouveaux clients/contacts », peut varier sensiblement.
