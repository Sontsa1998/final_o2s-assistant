## 109. FAQ – Editions

Comment insérer mon logo dans les éditions PDF ?. Comment insérer mon logo dans les éditions PDF ? A partir de Services , vous avez la possibilité d’insérer le logo de votre choix. Services Dans Services , cliquez sur l’onglet Personnalisation . Dans l’arborescence à gauche, cliquez sur Logos > Logo Impression . Dans le panneau de droite, cochez la case Logo Impression afin d’activer cette option. Cliquez sur le bouton Parcourir à droite de « Nouvelle image ». Depuis l’emplacement de votre choix, sélectionnez le fichier image du logo. Cliquez sur Enregistrer . Votre logo figurera alors dans vos éditions.
