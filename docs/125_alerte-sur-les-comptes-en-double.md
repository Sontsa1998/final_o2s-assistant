## 125. Alerte sur les comptes en double

Fonction. Fonction Cette alerte a pour but de vous avertir de la présence de comptes en double. Elle est automatiquement créée et générée par O2S suite à la détection de doublons dans votre base de comptes O2S. Traitement de l’alerte. Traitement de l’alerte En cliquant sur l’alerte, la fenêtre Liste des comptes en double s’ouvre : Liste des comptes en double  Plusieurs options s’offrent à vous : FONCTION DESCRIPTION Actions Fusionner le compte y (qui sera supprimé) vers le compte x (qui sera conservé) : seul le compte x figurera dans votre base. Notez que dans certains cas répondant à des règles de priorité de conservation des comptes, une action Fusionner le compte x (qui sera supprimé) vers le compte y (qui sera conservé) sera également disponible. Dans ce cas, veillez à sélectionner l’action la plus pertinente quant à ce compte en particulier. Conserver les 2 comptes : la situation actuelle perdurera ; les 2 comptes seront présents dans votre base. Reporter le traitement de l’alerte : le compte réapparaîtra toujours dans les alertes de ce type tant qu’aucune action définitive ( Fusionner ou Conserver les 2 comptes ) n’aura pas été effectuée. Ce choix est conservé même si vous fermez la fenêtre de traitement des alertes et que vous l’ouvrez à nouveau. Export Excel Crée une liste des actions effectuées pour chaque compte en doublon dans le format tableur Excel. Réinitialiser Bouton permettant de revenir à l’état d’alerte préconisé initialement par O2S. Tout reporter Bouton permettant de choisir l’action Reporter pour tous les comptes présents dans l’alerte, en un seul clic. OK Ferme la fenêtre en prenant en compte vos modifications. Dans ce cas, sélectionnez Reporter le traitement l’alerte dans la colonne « Actions » du compte.
