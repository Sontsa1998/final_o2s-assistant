## 385. Mouvements manquants

Mouvements manquants


1. Connaissance


1.1 : Description

Les mouvements, ou opérations, sont des évènements de différentes nature qui surviennent régulièrement ou non et impactent la vie et la valorisation du contrat. La complétude d'un historique mouvement permet de produire des claculs de gains (différence entre les collectes et les retraits) fiables, et permet au conseiller de disposer d'une information exhaustive dans le cadre de son conseil. Le client souscripteur du contrat dispose quant à lui d'une vue détaillée sur la vie de son contrat. Cependant, toutes les sources d'agrégation ne transmettent pas les mouvements, et pas systématiquement des historiques complets de mouvement. Il convient donc de consulter la documentation de la source d'agrégation concernée afin de savoir si les mouvements peuvent être agrégés, quels types de mouvements et sur quelle antériorité d'historique.
Fournir à l'utilisateur une explication claire des raisons possibles de l'absence du mouvement. Guider l'utilisateur à travers les étapes de vérification qu'il peut effectuer lui-même. Si le problème persiste après les vérifications initiales, proposer de soumettre le cas à l'équipe technique. Demander l'autorisation de faire suivre la conversation à l'assistance pour éviter une double saisie. Collecter les informations nécessaires pour l'escalade à une équipe technique.

1.2 Méthode


Hypothèse : Certaines sources d'agrégation ne fournissent pas tous les types de mouvements, voire aucun mouvement.
Action : Vérifier dans la documentation si la source d'agrégation concernée met à disposition le type de mouvement recherché par l'utilisateur.

Hypothèse : L'application applique par défaut des filtres qui peuvent masquer certains mouvements.
Action : Encourager l'utilisateur à vérifier et ajuster ses paramètres de filtrage.

Hypothèse : Les mouvements sont généralement agrégés dans les 15 jours suivant leur date de comptabilité.
Action : Vérifier la date du mouvement concerné.

Hypothèse : L'utilisateur peut avoir saisi le mouvement manuellement ou l'avoir enregistré en attente de validation. Cela est documenté sur la page suivante https://o2s-help.harvest.fr/mouvements-en-attente/
Action : Vérifier si le mouvement existe dans les saisies manuelles ou les recommandations en attente.

Hypothèse : L'application permet la saisie manuelle des mouvements manquants : https://o2s-help.harvest.fr/faq-portefeuille-et-comptes/#mvt-manuel
Action : Informer l'utilisateur de cette option.

Hypothèse : Des problèmes peuvent affecter temporairement l'agrégation des données. Les incidents en cours sont signalés sur cette page : https://o2s-help.harvest.fr/meteo-agregation/
Action : Vérifier les incidents en cours liés à la source d'agrégation. Un incident peut bloquer l'agrégation dans son ensemble ou celle des mouvements en particulier pour une source donnée.
