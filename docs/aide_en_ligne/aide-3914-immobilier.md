La gestion des biens immobiliers s’effectue dans l’espace Autres > Immobilier du module Contacts de votre client. Celui-ci se compose d’un tableau récapitulatif du patrimoine immobilier du contact et de 3 onglets disposant d’actions définies : Autres > Immobilier Contacts L’onglet Prêt n’apparaît que si vous avez défini un prêt pour le bien immobilier. L’onglet Epargne n’apparaît que si vous avez défini un adossement pour le prêt. Volet / Zone Informations Immobilier Dans cet onglet, renseignez les informations afférentes au bien immobilier (adresse, mode d’acquisition, etc.).

### Immobilier

Dans cet onglet, renseignez les informations afférentes au bien immobilier (adresse, mode d’acquisition, etc.).

### Acquisition

Vous pouvez renseigner ici les informations concernant la promotion, la gestion, le notaire et l’expert-comptable du bien immobilier. Pour chacun des intervenants vous pouvez définir et gérer un ensemble de listes vous permettant d’éviter de futures saisies superflues dans le cas où vous travaillez régulièrement avec les mêmes intervenants.

### Prêt

En effectuant un clic droit sur un bien immobilier puis en choisissant Ajouter prêt, vous pouvez accéder à différentes actions indiquées ci-dessous : Note : dans l’onglet Immobilier, si vous cliquez sur le bouton-radio Oui de ‘Financement à crédit’, l’onglet Prêt apparaît automatiquement. Modifier le prêt Ajustez si besoin les informations initialement saisies sur le prêt. Supprimer le prêt Supprimez définitivement le prêt. Ajouter un adossement : Note : pour ajouter un adossement, le mode de remboursement du prêt doit être « in-fine » Pour ajouter un adossement, sélectionnez la ligne du prêt dans l’onglet Financement. Cliquez avec le bouton droit sur Ajouter adossement, saisissez ensuite les informations relatives à l’adossement sur la base du contrat d’assurance vie adossé. Cliquez sur Enregistrer. Modifier le compte de prélèvement Pour spécifier le compte de prélèvement, faites un clic droit sur la ligne du prêt en question puis cliquez sur le bouton Modifier l’assurance du prêt. Ce compte comporte les coordonnées bancaires du client, et permet d’effectuer le prélèvement des échéances. Ajouter / Modifier l’assurance du prêt Cliquez sur le bouton Modifier l’assurance du prêt pour ajouter/modifier une assurance à un prêt. Modifier l’établissement prêteur Il s’agit des cordonnées de la banque prêteuse (nom, adresse, tel). Pour modifier ces informations, il suffit de cliquer sur Modifier l’établissement prêteur. Export Produisez un document au format PDF ou Excel.

### Epargne

Modifier l’adossement Ajustez si nécessaire les informations saisies initialement sur l’adossement concernant le prêt. Supprimer l’adossement Supprimez définitivement l’adossement. Ajouter un versement exceptionnel / périodique Pour ajouter un nouveau versement, sélectionnez l’onglet Epargne après avoir choisi le prêt puis cliquez avec le bouton droit sur Ajouter un versement. Saisissez les champs de cette fenêtre puis enregistrez les informations pour ajouter le versement.

Modifier l’établissement prêteur

### Ajout d’un bien immobilier

Un bien peut être ajouté au patrimoine immobilier du client : Cliquez sur Ajouter un immeuble dans la barre de menus. Remplissez le formulaire du bien et enregistrez pour ajouter l’immobilier au patrimoine géré de ce client en cliquant sur le bouton Enregistrer. Ajout d’un prêt pour un bien immobilier.

### Ajout d’un prêt pour un bien immobilier

Cliquez avec le bouton droit sur la ligne concernant le bien immobilier en question puis cliquez avec le bouton gauche sur Ajouter prêt. Saisissez les données relatives au prêt puis cliquer sur le bouton OK pour valider. Vous disposez alors d’un onglet Prêt. La procédure est identique dans le cas d’un ajout d’assurance pour un bien immobilier donné. Avant d’ajouter un prêt, vous devez activer l’option financement en cliquant sur Oui dans « Financement ».

### Edition des biens immobiliers

En cliquant sur l’icône PDF : en haut à droite du tableau récapitulatif de l’ensemble des biens immobiliers, vous pouvez générer une édition PDF de l’ensemble des biens immobiliers de votre client. en haut à droite d’un bien immobilier, vous pouvez générer une édition PDF de celui-ci.
