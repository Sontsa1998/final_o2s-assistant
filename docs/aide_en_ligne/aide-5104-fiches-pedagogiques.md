### Fiches produits

Utilisez les fiches produits ci-dessous pour présenter à votre client les produits que vous lui recommandez. Envoyez les fiches produits (pdf remplissable) à votre client afin qu’il réponde aux tests de connaissances sur les produits que vous lui recommandez et faites progresser ses connaissances. Ces fiches peuvent être intégrées dans votre GED Cabinet pour être utilisées directement depuis O2S.

### Fiche produit

Produits monétaires.

### Produits obligataires

Actions. SCPI. OPCI.

### Produits structurés

SOFICA.

### Actions complexes

Tracker. CFD. Futures. Options. Warrants. Turbos.
