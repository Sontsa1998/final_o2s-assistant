Fiche d'agrégation du partenaire **Cardif** dans O2S.

#### À savoir

Afin que votre demande d'agrégation puisse etre validée et fonctionnelle, vous devez vous abonner au format progestor pour la mise à disposition des fichiers sur l'extranet de Cardif. Votre code apporteur à paramétrer est le plus petit présent dans le fichier. Les mouvements peuvent être agrégés sur une profondeur de 1 an glissant Les données de Cardif sont agrégées depuis l'extranet https://finagora.cardif.fr/web/finagora/login.
