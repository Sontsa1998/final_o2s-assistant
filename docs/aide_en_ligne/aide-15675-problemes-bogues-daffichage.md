## Comment avoir une barre de défilement plus large ?

Pour augmenter l’épaisseur des barres de défilement dans O2S et faciliter leur utilisation, suivez ces étapes : Ouvrez les Paramètres de Windows : cliquez sur le bouton Démarrer puis saisissez « Paramètres » dans la barre de recherche, ou utilisez le raccourci clavier Windows + I. Dans la fenêtre des Paramètres, sélectionnez Accessibilité dans le menu de gauche. Cliquez ensuite sur Effets visuels. Activez l’option Toujours afficher les barres de défilement en basculant le bouton correspondant sur Activé.

### Ouverture d’O2S dans plusieurs onglets de votre navigateur

Des problèmes d’affichage peuvent survenir si vous ouvrez O2S sur plusieurs onglets de votre navigateur. Pour rappel, O2S doit être utilisé sur un seul onglet à la fois. Si vous respectez cette consigne et que le problème persiste, il est probable que votre navigateur ne puisse pas enregistrer de nouvelles informations. Dans ce cas, il est nécessaire de nettoyer les cookies et les données temporaires de votre navigateur, puis de relancer O2S. nettoyer les cookies et les données temporaires Les étapes ci-dessous vous guideront pour effectuer cette opération en fonction de votre navigateur : Google Chrome.

## Google Chrome

Ouvrez Google Chrome sur votre ordinateur. Cliquez sur le menu représenté par trois points verticaux en haut à droite de la fenêtre. Dans le menu déroulant, sélectionnez Plus d’outils, puis cliquez sur Effacer les données de navigation. Dans la fenêtre qui s’affiche : En haut, choisissez une période (par exemple, « Toutes les périodes »). Cochez les cases « Cookies et données de site » et « Images et fichiers en cache ». Fermez Google Chrome, puis relancez-le.

## Mozilla Firefox

Ouvrez Mozilla Firefox sur votre ordinateur. Cliquez sur le menu représenté par trois barres horizontales en haut à droite, puis sélectionnez Paramètres. Dans le panneau de gauche, cliquez sur Vie privée et sécurité. Dans la section Cookies et données de sites, cliquez sur le bouton Effacer les données…. Décochez la case « Cookies et données de sites ». Cochez la case « Contenu web en cache ». Fermez Mozilla Firefox, puis relancez-le. Important Pour éviter ces désagréments, veillez à toujours utiliser O2S sur un seul onglet de votre navigateur. Si le problème persiste après avoir suivi ces étapes, contactez le support technique pour une assistance supplémentaire. O2S est lent ou affiche une page blanche.

Si O2S met du temps à charger ou affiche une page blanche : Videz le cache de votre navigateur (Ctrl+Shift+Suppr). Vérifiez votre connexion internet : testez votre débit sur un site comme speedtest.net . Fermez les onglets inutiles : un grand nombre d’onglets ouverts peut ralentir votre navigateur. Désactivez les extensions de navigateur susceptibles d’interférer. Testez en navigation privée : si O2S fonctionne en navigation privée, le problème vient d’une extension ou du cache. Si le problème persiste sur plusieurs postes de votre cabinet, il peut s’agir d’un incident temporaire. Contactez l’Assistance O2S .
