Ces variables sont uniquement utilisables avec la Déclaration d’adéquation personnalisable (format Word) .

### Tableau des variables

Vous souhaitez visualiser l’apparence finale de certaines variables avant de les insérer dans votre document ? Pour vous accompagner, nous mettons à votre disposition un tableau regroupant les principales variables « projet »; vous pourrez ainsi prévisualiser leur rendu exact tel qu’il apparaitra dans votre déclaration d’adéquation, sans avoir à utiliser Word. Prévisualiser les variables « projet » ATTENTION ! Vous devez impérativement saisir les variables telles qu’elles apparaissent avec les 2 signes ‘$’, dans le tableau ci-dessous. Nous vous conseillons de les copier depuis la présente page, puis de les coller dans votre document modèle Word de Déclaration d’adéquation. Par exemple, vous devez copier $PROJET_CLASSIFICATION_CLIENT_MIF$ si vous souhaitez insérer les données correspondant à la Classification MIF du client.
