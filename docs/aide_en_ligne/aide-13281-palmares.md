L’encart Palmarès, visible par défaut sur la page d’ Accueil d’O2S, présente un tableau des fonds classés selon leur tendance (haussière ou baissière), ainsi que leurs performances et leur volatilité. Note : si le palmarès ne figure ni dans l’accueil, ni dans l’onglet Pilotage d’O2S, rendez-vous dans le module Services > Modules > Accueil et pilotage > Organisation, et cochez Palmarès dans l’onglet de votre choix. Palmarès Utilisation. Pour personnaliser votre affichage, utilisez les deux listes déroulantes pour sélectionner l’indicateur et la période souhaitée. Les en-têtes du tableau sont cliquables, vous permettant de trier les fonds par ordre alphabétique, ainsi que par performance ou volatilité, tant en croissance qu’en décroissance.

À droite de chaque fonds, vous trouverez un bouton avec trois points qui vous permet de : Rechercher les contacts détenant ce fonds.

### Rechercher les contacts détenant ce fonds

Les résultats s’afficheront dans le module Requêtes, où vous pourrez effectuer diverses actions. Rechercher les comptes sur lesquels ce fonds est présent. Les résultats apparaîtront également dans le module Requêtes, vous permettant d’agir en conséquence. Accéder à des informations détaillées sur ce fonds. Le cas échéant, consulter la fiche de synthèse Quantalys. Accéder au Document d’Informations Clés pour l’Investisseur (DIC). Paramétrage. Pour ajuster vos paramètres, cliquez sur l’icône en forme de loupe en haut à droite. Sélectionnez soit le bouton Mon palmarès, soit Palmarès du cabinet, selon que vous souhaitez modifier les fonds gérés par vous-même ou par l’ensemble de votre structure. Cliquez sur le bouton Tous les fonds gérés pour ajouter les 100 premiers supports avec les encours les plus importants.

Les fonds gérés par le conseiller pour inclure les 100 premiers supports gérés par le conseiller avec les encours les plus significatifs. Si vous notez la présence d’un fonds ne figurant plus dans les portefeuilles de vos client, vous pouvez le sélectionner puis le supprimer. Notes Le tableau peut contenir un maximum de 100 fonds. Pour en supprimer un fonds dans Mon palmarès, cliquez sur la loupe en haut à droite, puis cliquez sur le bouton Mon palmarès, sélectionnez le fonds à supprimer et cliquez sur le bouton Supprimer, ou choisissez Tout Supprimer. Lorsque moins de 100 fonds sont affichés, vous pouvez ajouter au moins un fonds supplémentaire. Si vous souhaitez faire figurer le graphe d’évolution des OPCVM dans le palmarès, rendez-vous dans le module Services > Modules > Accueil et pilotage > Palmarès, et cochez Afficher le graphe d’évolution des OPCVM puis enregistrez.
