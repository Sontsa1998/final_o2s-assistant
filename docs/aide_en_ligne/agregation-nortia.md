#### À savoir

Votre code apporteur est composé d'une serie 4 à 5 chiffres ou d'une longue serie de chiffres et de lettres. Ce code apporteur dédié couvre les contrats Nortia Nelia ainsi que les contrats assurés auprès de Swisslife, Generali, Wealins et Naxitis Life. Assurez-vous bien d'avoir complété et signé la lettre d'autorisation. Les mouvements peuvent être agrégés sur une profondeur de 1 mois glissant
