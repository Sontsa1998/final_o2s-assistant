O2S vous permet de personnaliser son interface selon vos besoins et les tâches que vous accomplissez chaque jour.

### Trouver les options de personnalisation

La plupart des réglages et options sont disponibles dans le module Services, accessible en cliquant sur votre menu nominatif (en haut à droite).

### Personnaliser les modules

Services, vous trouverez plusieurs onglets : Modules Editions Personnalisation Modèles d’affaires Opérations commerciales Emails Synchronisation MoneyPitch Chaque onglet est divisé en deux parties : À gauche : une arborescence listant les fonctionnalités. À droite : les options de configuration pour la fonctionnalité sélectionnée. Pour modifier un réglage : Sélectionnez la fonctionnalité dans la liste de gauche. Modifiez les options à droite selon vos besoins. Cliquez toujours sur Enregistrer pour sauvegarder vos changements. ⚠️ Accès réservé Pour accéder au module Services, vous devez avoir les droits nécessaires. Si besoin, contactez l’administrateur d’O2S de votre organisation.
