Les prérequis nécessaires et préconisés par Harvest pour l’utilisation de la solution O2S sont les suivants : Navigateurs web.

### Navigateurs web

O2S nécessite un dispositif permettant l’utilisation dans de bonnes conditions d’un navigateur internet. Il n’existe pas de pré-requis particuliers concernant le système d’exploitation qui peut être Windows, macOS, iPadOS, Android ou Linux. Les navigateurs internet supportés sont : Chrome : les 2 dernières versions majeures (Windows, macOS, Linux) Firefox : les 2 dernières versions majeures (Windows, macOS, Linux) Edge : les 2 dernières versions majeures (Windows, macOS) Safari : les 2 dernières versions mineures (macOS) Harvest ne s’engage pas à maintenir une compatibilité avec les autres navigateurs.

### Affichage & saisie

L’usage d’O2S est prévu avec une largeur minimale de 1024 pixels. Pour la navigation et la saisie des formulaires, O2S est compatible avec les dispositifs d’entrées suivants : Claviers Souris Ecrans tactiles Claviers Souris Ecrans tactiles Réseau. O2S nécessite une connexion internet permanente à minima ADSL ou 4G. La réactivité de l’application sera directement liée à la qualité de la connexion internet. Firewall / Antivirus Firewall / Antivirus Pour le bon fonctionnement d’O2S, les éléments de sécurité du poste et de l’infrastructure de la société, doivent laisser passer librement les domaines suivants pour le protocole HTTPS : *.harvest.fr *.office2s.com *.moneypitch.fr *.feefty.com fonts.googleapis.com fonts.gstatic.com Le protocole Server Sent Event doit également être autorisé entre le navigateur et Harvest.

Editions. L’aperçu et l’impression des rapports d’éditions à travers O2S ne nécessitent pas de plugin, ni de logiciels supplémentaires sur le poste de travail. Les rapports d’éditions peuvent être sauvegardés au format PDF ou DOCX. L’accès à ces documents nécessitent l’installation d’un lecteur PDF ou Office Word sur le poste. Versions d’Office Word supportées : Office 2019 Office 365 Office 2019 Office 365 Pour les documents Office Word, Harvest ne s’engage pas à maintenir la compatibilité DOCX avec des logiciels tiers tels que les suites bureautique OpenOffice ou LibreOffice, etc.
