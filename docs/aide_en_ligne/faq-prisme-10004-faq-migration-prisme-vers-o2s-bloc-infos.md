Chers utilisateurs,. Pour obtenir toutes les informations sur la migration de vos données Prisme vers O2S, vous devez consulter la présente FAQ. Elle décrit certaines actions requises et indispensables que vous devrez effectuer afin d’assurer une migration optimale vers O2S et d’éviter tout désagrément futur. devez actions requises et indispensables devrez effectuer Nous attirons notamment votre attention sur les points suivants : votre attention sur les points suivants Action requise : il est impératif de nettoyer vos bases Prisme et notamment de supprimer les comptes clôturés . Vous retrouverez dans O2S la plupart des données de vos clients Prisme. Nous vous encourageons vivement cependant à prendre connaissance dès maintenant des données qui ne seront pas migrées vers O2S ainsi que des données traitées différemment entre Prisme et O2S .

Action requise : pour disposer de l’ agrégation dans O2S, vous devez vous-même vous rapprocher de vos partenaires afin que vos données soient actualisées dans votre O2S; consultez la section Demander l’agrégation dans O2S auprès de vos partenaires . A noter également : La reprise de l’agrégation dans O2S peut avoir pour effet de créer des comptes (contrats) et mouvements en double . Dans O2S, vous pouvez suivre l’ avancement de la demande d’agrégation de vos partenaires . Action requise : vos clients disposant de Nexus vont bientôt utiliser MoneyPitch, le portail patrimonial d’O2S : pour préparer cette transition, vous devez effectuer des actions dans Prisme avant la migration , et des actions dans O2S pendant la migration .

Nous vous recommandons ensuite de lire la section MoneyPitch . (ne concerne pas les cabinets possédant déjà un O2S) Coût : la migration des données de Prisme vers O2S est offerte.
