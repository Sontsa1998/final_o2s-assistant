## Pré-requis

Pour pouvoir fonctionner pleinement, les tablettes et les téléphones Android doivent être liés à un compte Google. Par conséquent, si vous le souhaitez, vous pouvez synchroniser votre appareil avec O2S en passant par Google Agenda. Pour mettre en place cette synchronisation, reportez-vous à la rubrique Google Agenda . Si vous souhaitez mettre à jour directement O2S à partir de votre téléphone sans passer par Google agenda, vous devez télécharger une application. Pour cela, allez sur Google Play, puis cherchez et achetez l’application CalendarSync.

## Paramétrage

Lancez votre application, cliquez sur le bouton Menu de votre téléphone et sélectionnez Create new WebICal. Ensuite dans l’écran qui s’affiche, vous devez saisir ces informations : – Name : indiquez O2S – URL : https://www.office2s.com/office2s/caldav.php/calendars/ id /o2s – Username : id (avec id = identifiant O2S) – Password : mot de passe O2S Lancez votre application, cliquez sur le bouton Menu de votre téléphone et sélectionnez Create new WebICal. Attention : vous devez saisir l’identifiant et le mot de passe avec lequel vous accédez à Harvest Connect ! Si vous accédez à O2S en mode SSO, contactez l’administrateur O2S de votre société. Ensuite cochez les cases Use two way sync, Is a active Webical et Primary Webical.

Cliquez sur Save changes. Validez la création de ce calendrier. Retournez sur le menu général de l’application et cliquez sur Préférences. Vérifiez que dans le menu Import options les cases suivantes sont cochées; dans le cas contraire, cochez-les : Validez la création de ce calendrier. App specific options : Dans le menu Autosync : Dans le menu App specific options : App specific options Dans le menu Autosync : Autosync Enfin positionnez la périodicité de la synchronisation en cliquant sur Autosync period. Maintenant, si vous le souhaitez, vous pouvez déclencher manuellement la synchronisation de votre téléphone avec O2S; pour cela cliquez sur le bouton Parse de l’application. Parse Les tâches. Les tâches Les tâches ne sont pas synchronisées entre O2S et l’agenda Android car la gestion des tâches n’est possible sous Android qu’avec une application tierce.
