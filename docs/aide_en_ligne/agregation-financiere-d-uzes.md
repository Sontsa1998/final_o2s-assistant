Fiche d'agrégation du partenaire **Financière d'Uzès** dans O2S.

#### À savoir

Votre code apporteur est composé de 3 chiffres. Assurez-vous d'avoir bien complété et signé la lettre d'autorisation. Les mouvements peuvent être agrégés sur une profondeur de 3 mois glissants

#### Produits agrégés

Asv (Financière d'Uzès), Compte titres (Financière d'Uzes), PEA (Financière d'Uzès), PEA-PME (Financière d'Uzès)

#### Prix d'achat moyen

Les prix d'achat moyens sont transmis par ce fournisseur.

#### Mouvements agrégés

Transfert sortant, Vente de titres, Frais de gestion, Achat de titres, Distribution de revenus (coupons, SCPI), Remboursement de prime, Sortie d'espèces, Hors Nomenclature, Entrée d'espèces, Transfert entrant

#### Fréquence d'agrégation

La fréquence d'agrégation est quotidienne
