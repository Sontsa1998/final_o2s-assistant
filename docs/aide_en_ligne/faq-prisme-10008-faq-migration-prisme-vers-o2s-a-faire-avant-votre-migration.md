1. Action requise : NETTOYER VOS BASES PRISME. Afin d’avoir une base clients et utilisateurs dans O2S la plus à jour possible, nous vous recommandons vivement, dès aujourd’hui (au pire au moins 1 semaine avant la date effective de votre migration), de nettoyer vos bases Prisme en supprimant : dès aujourd’hui au moins 1 semaine avant la date effective de votre migration, nettoyer vos bases Prisme en supprimant les anciens clients et anciens prospects avec leurs comptes et documents liés les utilisateurs de votre équipes qui ne sont plus actifs (anciens collaborateurs) les comptes clôturés les comptes Nexus (en les désactivant ) non utilisés afin de ne pas les migrer globalement toutes les données qui ne sont plus utiles Les données non supprimées et migrées peuvent entrainer une facturation supplémentaire dans O2S.

Méthode : Méthode : Méthode : Pour supprimer une personne, rendez-vous sur la fiche de la personne au niveau de l'onglet "informations" sur la gauche de l'écran. Dans l'encart de droite, cliquer sur "Supprimer la personne" puis "valider". Attention, tous les contrats de cette personne seront supprimés. Pour supprimer un collaborateur, vous devez contacter le support@manymore.fr (mailto:support@manymore.fr). Toutefois, avant de faire cette demande, il peut être nécessaire de transférer les clients et les contrats de ce collaborateur vers un autre collaborateur actif. Les collaborateurs inactifs seront migrés dans O2S. Pour transférer un collaborateur vers un autre collaborateur actif, rendez-vous sur l'onglet "Gérer".

Choisissez sur la gauche l'onglet "Changement de collaborateur". Indiquez à gauche le collaborateur "sortant" et à droite le collaborateur récupérant les clients. Cliquez sur "Transférer les clients". Pour supprimer un document de la GED, rendez-vous sur la fiche de la personne au niveau de l'onglet "GED" sur la gauche de l'écran. La liste des documents s'ouvre, cliquez sur la croix à droite du document pour le supprimer. SAUVEGARDER LES DONNÉES PRISME. Vous pouvez sauvegarder les données Prisme de vos clients en suivant la procédure de récupération des données dans Prisme . Cette procédure est recommandée pour sauvegarder les données qui ne sont pas migrées automatiquement vers O2S . 3. DEMANDER L’AGRÉGATION DANS O2S AUPRÈS DE VOS PARTENAIRES.

Même si vous avez donné les accords à vos partenaires pour disposer de l'agrégation dans Prisme, vous devez leur envoyer un mail ou un courrier pour leur demander d'envoyer vos données vers O2S dorénavant. Vous devez impérativement consulter la liste des actions que vous devrez effectuer pour chaque partenaire . Nous vous invitons à contacter les fournisseurs pour l’envoi de fichiers à Harvest au dernier moment, pour que l’agrégation ne soit pas interrompue trop tôt dans Prisme. 4. PRÉPARER VOS CLIENTS NEXUS A LA TRANSITION VERS MONEYPITCH. Nexus vont bientôt utiliser MoneyPitch, le portail patrimoniale d'O2S. Nous vous conseillons de lire la page dédiée à la préparation de cette transition pour qu'elle se déroule dans les meilleures conditions.

(ne concerne pas les cabinets possédant déjà un O2S)
