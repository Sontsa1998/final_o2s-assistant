## Fonction

Cette alerte a pour but de vous avertir de la présence de mouvements en attente. Cette alerte est automatiquement créée et générée par O2S. Elle vous permet de relier des mouvements en attente à des mouvements importés. Son traitement est facultatif, les mouvements continueront à être importés même si vous ne traitez pas cette alerte.

## Traitement de l’alerte

En cliquant sur l’alerte, la fenêtre Liste des mouvements en attente s’ouvre : Liste des mouvements en attente Plusieurs options s’offrent à vous : Fonction Description Icône loupe Affiche le détail du compte dans le portefeuille du client.

| Fonction | Description |
|---|---|
| Icône loupe | Affiche le détail du compte dans le portefeuille du client. |
| Actions | Reporter le traitement : le mouvement réapparaîtra toujours dans les alertes de ce type tant qu’aucune action définitive (Associer) n’aura pas été effectuée. Associer le mouvement importé : le mouvement en attente est apparié au mouvement actif du compte correspondant. Dans ce cas, dans la colonne « Libellé mouvement importé », cliquez sur l’icône au niveau de chaque mouvement afin de sélectionner le mouvement associé. Dans O2S, le mouvement en attente devient alors un mouvement avec le statut « Rapproché». |
| Export Excel | Crée une liste des actions effectuées pour chaque mouvement au format tableur Excel. |
| Réinitialiser | Permet de revenir à l’état initial de l’alerte. |
| OK | Ferme la fenêtre en prenant en compte vos modifications. |
| Annuler | Ferme la fenêtre sans prendre en compte vos modifications. |

## Exemples de traitement

Cas 1 : Associer le mouvement importé Vous êtes sûr que le mouvement importé correspond bien au mouvement en attente dans O2S. Dans ce cas, sélectionnez Associer le mouvement dans la colonne « Actions » du mouvement. Cas 2 : Reporter le traitement d’un mouvement Vous n’êtes pas sûr que le mouvement est bien celui que vous souhaitez associer dans O2S, vous souhaitez effectuer des vérifications au préalable et, au besoin, ajouter ce mouvement ultérieurement.
