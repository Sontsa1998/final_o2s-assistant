La communication avec vos clients MoneyPitch peut s’effectuer via la messagerie sécurisée entre O2S et MoneyPitch. Cette fonctionnalité vous offre la possibilité de centraliser tous les échanges réalisés avec vos clients en un seul endroit sécurisé. Email ou message…Quelle différence ? Si vous envoyez un email , votre client le recevra en dehors de MoneyPitch, dans sa boite mails personnelle. Si vous envoyez un message, celui-ci arrivera dans le MoneyPitch de votre client, au niveau de la messagerie sécurisée. Envoi d’un message à votre client. Pour envoyer un message : Cliquez sur (courrier),dans la partie supérieure d’O2S, pour accéder à la fenêtre Emails et messages MoneyPitch. Cliquez sur l’onglet Message reçu ou Message envoyé puis sur Envoyer un message.

Dans la fenêtre Message, cliquez sur (destinataire) en haut à gauche, puis sur Insérer les contacts, et recherchezsélectionnez le destinataire, en le cochant, puis cliquez sur Ajouter et OK. Notez que vous pouvez sélectionner plusieurs destinataires; dans ce cas, à l’aide du menu Variable O2S , il vous suffira d’insérer des variables dans le corps de votre message pour que chaque client reçoive un message personnalisé. Saisissez l’ Objet et votre Message. Pour ce dernier, utilisez la barre d’outils afin de le mettre en page. Notez que vous pouvez sélectionner une lettre type parmi celles déjà préenregistrées en cliquant sur le bouton Insérer un email type. Vous pouvez également insérer un lien en cliquant sur l’icône (lien).

Joignez une image en cliquant sur Insérer > Image…. Si vous désirez que le message envoyé figure dans la liste de l’onglet Suivi du module Contacts, cliquez sur le bouton radio Oui au niveau de Enregistrer dans le suivi. Une fois votre message prêt, cliquez sur Envoyer. Objet Message Vous ne pouvez pas envoyer de pièce jointe via la messagerie. Notez que vous pouvez déposer vos documents dans la GED > MoneyPitch de votre client . Il pourra alors en prendre connaissance dans sa GED, dossier O2S-MoneyPitch. Si vous souhaitez envoyer une pièce jointe, vous devez envoyer un email en cliquant sur l’onglet Email reçu ou Email envoyé, ou bien encore, depuis votre liste de contacts, en sélectionnant le contact puis en cliquant sur sur Envoyer > Un email.

Pour vous envoyer un message, il suffit à votre client de cliquer sur le bouton Nouveau Message, saisir un objet, rédiger son message, puis cliquer sur Envoyer pour vous le faire parvenir. Note : chaque fichier intégré en pièce jointe ne doit pas excéder une taille de 10 Mo. Note : Réception des messages de vos clients.

### Réception des messages de vos clients

Vous êtes alerté des nouveaux messages via la pastille sur l’enveloppe en haut à droite dans O2S. Cliquez sur l’enveloppe; vous pouvez consulter le message dans Messages reçus.
