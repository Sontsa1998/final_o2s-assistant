## Pré-requis

Le module complémentaire « Lightning » doit être installé dans votre application Thunderbird pour permettre la synchronisation des agendas. Dans le cas contraire, vous pouvez le télécharger en cliquant sur Outils > Modules complémentaires de l’agenda Thunderbird. Puis dans la liste des modules disponibles, il suffit de sélectionner « Lightning » pour l’installer.

## Paramétrage de l’agenda O2S

Dans le menu, cliquez sur Nouveau, puis sur Agenda … : Nouveau Agenda Dans la fenêtre qui s’ouvre, sélectionnez Sur le réseau. Cliquez sur Suivant. Dans la fenêtre qui apparaît, cliquez sur le format CalDAV, saisissez votre identifiant O2S (id correspondant à votre identifiant O2S), puis dans la zone Emplacement, saisissez l’adresse figurant ci-dessous. https://www.office2s.com/office2s/caldav.php/calendars/id/o2s Attention : vous devez saisir l’identifiant et le mot de passe avec lequel vous accédez à Harvest Connect ! Si vous accédez à O2S en mode SSO, contactez l’administrateur O2S de votre société. Puis cliquez sur Suivant. Donnez un nom à votre agenda (par exemple « Agenda O2S »), voire une couleur afin de le différencier des autres agendas, et renseignez votre adresse email.

Dans la fenêtre d’authentification qui s’ouvre, saisissez vos identifiant O2S; pensez à enregistrer ces identifiants en cochant l’option prévue pour qu’à l’avenir la synchronisation soit « transparente ». Une fois validé, le calendrier O2S est opérationnel. Une fenêtre vous avertit alors que votre agenda a été créé : il figure maintenant dans liste des agendas de Thunderbird.

## Paramétrage de la synchronisation

La fréquence de mise à jour dans Thunderbird peut être paramétrée dans la fenêtre de propriétés de l’agenda.

## Propriétés

Faites un clic droit sur l’agenda O2S afin de faire apparaître le menu contextuel. Dans la fenêtre de paramétrage, choisissez la fréquence d’actualisation à l’aide de la liste déroulante Actualiser l’agenda. Si vous souhaitez obtenir une actualisation optimale, sélectionnez « Chaque minute ». Cliquez sur OK. Actualiser l’agenda OK

## Synchronisation

La synchronisation (ajout, modification, suppression) s’effectue dans les deux sens. Dans le cas de la création d’un rendez-vous dans Thunderbird, il vous faut également associer cet évènement au calendrier O2S pour que la synchronisation soit effective. Cliquez sur l’icône Inviter des participants afin de sélectionner les adresses email des destinataires de l’événement. Si l’adresse email d’un participant est reconnue dans O2S, celui-ci apparaîtra dans l’onglet « Participant ». Dans le cas contraire, il sera présent dans l’onglet « Autre participant ». Définissez le moment auquel le rappel de l’événement doit intervenir. Cet élément sera lui aussi synchronisé avec O2S.

## Tâches

Lors de la synchronisation, les tâches sont elles aussi synchronisées.
