L’utilisation de variables dans O2S permet de personnaliser les documents générés, tels que les emails, lettres-types et modèles Word, et Déclarations d’Adéquation en intégrant automatiquement des données spécifiques à chaque contact.. Possibilités offertes par l’utilisation de variables :. Personnalisation des documents : Les variables permettent d’insérer des informations spécifiques comme le nom, prénom, adresse, etc., directement dans les documents, rendant chaque envoi unique et pertinent pour le destinataire. Types de supports : Emails : En utilisant des variables, vous pouvez envoyer des emails personnalisés à plusieurs contacts en même temps. Lettres-types : Ces lettres peuvent être imprimées au format Word ou PDF, avec des variables intégrées pour personnaliser le contenu.

Vous pouvez créer des modèles dans Word, y insérer des variables, et les utiliser pour des envois personnalisés. Et notamment pour créer vos propres modèles de Déclaration d’Adéquation.

### Facilité d’utilisation

: pour les mails et les lettres-types, O2S propose une liste déroulante de variables que vous pouvez insérer facilement dans vos documents, ce qui simplifie le processus de personnalisation. Facilité d’utilisation : pour les mails et les lettres-types, O2S propose une liste déroulante de variables que vous pouvez insérer facilement dans vos documents, ce qui simplifie le processus de personnalisation. Comment utiliser les variables :. Insertion dans les emails : Accédez au module Requêtes et sélectionnez les contacts. Utilisez le menu (Actions) pour envoyer un email. Dans la fenêtre de rédaction, insérez des variables via la liste déroulante « Variables O2S » pour personnaliser le message. Dans le module Contacts, effectuez un clic droit sur un contact et choisissez d’imprimer un courrier (Word ou PDF).

Sélectionnez la lettre type souhaitée et modifiez-la si nécessaire en ajoutant des variables.

### Insertion dans les modèles

Word : Créez votre document dans Word en y insérant manuellement les variables (en les saisissant entre deux signes ‘$’). Enregistrez le document au format.docx et importez-le dans O2S via le module Services > Personnalisation > Paramétrage > Modèles Word ou Déclaration d’Adéquation. Remarques importantes :. Assurez-vous que les variables sont correctement orthographiées et entourées de signes ‘$’ pour qu’elles soient interprétées correctement. En résumé, l’utilisation de variables dans O2S permet de créer des documents personnalisés de manière efficace, améliorant ainsi la communication avec les contacts.
