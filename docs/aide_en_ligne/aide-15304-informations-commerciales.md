Présentation. Disponible dans votre onglet Pilotage d’O2S, l’encart Informations commerciales est un outil clé dans O2S, conçu pour vous fournir une vue d’ensemble des données essentielles de votre structure. Il regroupe des statistiques sur divers sujets tels que : Pilotage Informations commerciales Prospects et clients, Emails, rendez-vous, relances et fiches de suivi, Comptes gérés et agrégés, Encours et collecte brute, et autres indicateurs… Cet encart est accessible depuis la page Pilotage par défaut, mais il peut être déplacé vers la page Accueil selon vos préférences. Configuration de l’emplacement de l’encart.

### Configuration de l’emplacement de l’encart

Vous pouvez personnaliser l’emplacement de l’encart Informations commerciales dans O2S : Informations commerciales Par défaut : L’encart est affiché dans la page Pilotage. Pour le déplacer vers la page Accueil : A l’aide de votre menu utilisateur en haut à droite d’O2S, rendez-vous dans Services > Modules > Accueil et pilotage > Organisation. Décochez l’option dans la colonne Pilotage. Cochez l’option dans la colonne Accueil. Cliquez sur Enregistrer.

### Fonctionnalités de l’encart

L’encart Informations commerciales offre plusieurs fonctionnalités pour analyser vos données : Informations commerciales Détail des informations : Cliquez sur l’icône loupe pour accéder au détail de chaque ligne. Vous pourrez explorer les données spécifiques à chaque catégorie. Personnalisation de l’affichage : Regroupements : Modifiez l’organisation des données grâce aux options situées en haut de la page. Filtres : Affinez votre analyse en appliquant des filtres disponibles en bas de la page. Niveaux de visualisation : Naviguez entre différents niveaux de détail pour une meilleure compréhension des informations, en cliquant sur les chevrons.
