Profil d’investisseur - Quels éléments sont restitués dans O2S ? Les réponses aux questionnaires du dernier profil d'investisseur établi dans Prisme ne sont pas migrés. Cependant, le résultat du profil investisseur est bien reporté. résultat Avant de réaliser un projet d’investissement dans O2S, vous devez impérativement établir un nouveau profil d’investisseur pour votre client dans O2S.
