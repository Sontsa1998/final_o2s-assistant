Le DCC est un document qui synthétise les informations clés sur votre client : situation familiale, patrimoine, fiscalité, revenus et objectifs. Il peut être généré pour : DCC Les personnes physiques : un modèle standard est disponible par défaut dans O2S. Les personnes morales : un modèle spécifique doit être créé à l’aide d’un document Word.

## Générer un DCC pour une personne physique (client)

Accédez au module Contacts. Dans la liste des contacts, cliquez sur le bouton (3 points) à droite de la ligne du client concerné. Sélectionnez Envoyer ou Imprimer.

## Envoyer ou Imprimer

Choisissez entre : DCC vierge : sans données préremplies. DCC imprimé : avec les informations connues sur le client dans O2S. Cliquez sur OK pour générer le document.

## Étape 1 : Créer un modèle Word DCC

Préparez un document Word contenant le texte et les variables O2S nécessaires . Notez que vous pouvez utiliser les variables de votre choix, dont celles qui concernent spécifiquement les personnes morales . Accédez à Services > Personnalisation > Modèles Word > Modèles Word. Cliquez sur Ajouter un modèle. Importez votre document Word en le glissant-déposant dans la zone en pointillés ou en cliquant pour le sélectionner. Donnez un nom explicite à votre modèle dans le champ Nom retenu (ex. : DCC Personne Morale). Une fois créé, le modèle apparaît dans la liste des modèles Word disponibles.

## Étape 2 : Générer le DCC

Dans le module Contacts, cliquez sur le bouton (3 points) à droite de la ligne de la personne morale concernée. Sélectionnez Imprimer > Un courrier à partir de la bibliothèque Word. Dans la fenêtre d’impression, choisissez le modèle Word DCC Personne Morale que vous avez créé. Le DCC personnalisé est généré et disponible dans le dossier de téléchargement de votre navigateur.
