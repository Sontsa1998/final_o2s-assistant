Présentation. L’accès de démonstration à MoneyPitch Premium est une fonctionnalité utile pour votre client, et pour vous-même : Votre client souhaite disposer de MoneyPitch ou MoneyPitch Premium mais aimerait pouvoir tester l’application avant de vous donner son accord. Vous souhaitez vous-même disposer d’un accès à MoneyPitch ou MoneyPitch Premium pour effectuer des démonstrations à vos clients, à distance. Dans tous les cas, l’accès de démonstration donnera accès à MoneyPitch Premium. Un accès de démonstration gratuit. Premium est gratuit (il ne vous est donc pas facturé). Un seul accès de démonstration est disponible par base O2S (donc pour votre société). Attention : étant donné qu’un seul accès de démonstration peut être activé à la fois, vous devez d’abord désactiver l’accès MoneyPitch Premium de démonstration d’un client avant d’en ouvrir un pour un autre client.

Attention : Activer l’accès de démonstration à MoneyPitch Premium.

### Droits requis

Avant toute chose, assurez-vous que dans le module d’ administration > Utilisateurs, vous-même ou bien l’utilisateur d’O2S disposez bien du Droit d’attribution des accès MoneyPitch Premium : administration > Utilisateurs Droit d’attribution des accès MoneyPitch Premium Par ailleurs, dans Administration > Profil utilisateur > Gestion des profils > Sélectionnez le profil > Contacts, vérifiez aussi que l’option Activation de MoneyPitch Premium est bien cochée. Note : si vous n’avez pas le droit d’accéder au module d’administration, contactez votre administrateur d’O2S. Note : Procédure. Dans le dossier de votre client, cliquez sur Activer MoneyPitch. Dans l’onglet MoneyPitch > Activation, sélectionnez MoneyPitch Premium dans la liste déroulante Activer / Désactiver l’accès.

Cliquez sur le bouton switch Accès de démonstration. Renseignez l’adresse email de votre client (ou bien la vôtre dans le cas où vous voulez utiliser un MoneyPitch Premium pour effectuer des démonstrations à distance avec un client). Cliquez sur Enregistrer. Un mail est alors envoyé à votre client (ou à vous-même), il lui suffit ensuite de créer un mot de passe; votre client (ou bien vous-même) pourrez alors accéder à une version MoneyPitch Premium de démonstration.

### Premium pour un autre client

Pour activer un MoneyPitch Premium de démonstration à un autre client, vous devez d’abord désactiver l’ancien accès de démonstration. A l’aide de votre menu utilisateur (votre nom) en haut à droite d’O2S, rendez-vous dans l’ Espace Abonnement > Consommation, puis cliquez sur la loupe à droite de l’encart MoneyPitch premium : Espace Abonnement > Consommation MoneyPitch premium Il vous suffit ensuite de repérer l’accès de démonstration dans la liste puis de cliquer sur le bouton switch dans la colonne Accès actif afin de le désactiver. OK pour valider. Vous pouvez alors suivre la procédure ci-dessus pour activer un accès de démonstration à l’autre client.
