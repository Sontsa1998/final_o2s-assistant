O2S intègre un outil élaboré d’envoi de courriers électroniques que vous pouvez personnaliser.

### Envoi d’email

Pour envoyer un message : Cliquez sur,dans la partie supérieure d’O2S, pour accéder à la fenêtre Emails et messages MoneyPitch. Dans l’onglet Emails envoyés, cliquez sur Envoyer un email. Dans la fenêtre Message, cliquez sur A / Cc / Cci pour sélectionner le(s) destinataire(s); cochez-le(s), puis cliquez sur Ajouter et OK. Notez que vous pouvez sélectionner plusieurs destinataires; dans ce cas, à l’aide du menu Variable O2S , il vous suffira d’insérer des variables dans le corps de votre message pour que chaque client reçoive un email personnalisé. Saisissez l’ Objet et votre Message. Notez que vous pouvez sélectionner une lettre type parmi celles déjà préenregistrées en cliquant sur le bouton Insérer un email type.

Vous pouvez également insérer une image en effectuant un copier-coller dans le corps du texte du mail. Vous pouvez aussi choisir de demander à votre destinataire de vous faire parvenir un accusé de réception*, en cliquant sur le bouton radio prévu à cet effet. Si vous désirez que l’envoi de l’email figure dans la liste de l’onglet Suivi du module Contacts, sélectionnez le bouton radio Oui. Saisissez l’objet et le texte du message Une fois votre mail finalisé, cliquez sur Envoyer. Envoyer *Note sur l’accusé de réception Lorsque vous envoyez un email depuis O2S avec l’option « Accusé de réception » activée (bouton-radio positionné sur « Oui »), il est important de savoir que la réception de cet accusé dépend entièrement des paramètres configurés par le destinataire dans son application de messagerie.

Par exemple, dans Outlook (voir illustration ci-dessous), si le destinataire a choisi de ne pas envoyer automatiquement d’accusé de réception, vous, en tant qu’expéditeur, ne recevrez pas cette confirmation. *Note sur l’accusé de réception Le bouton Réinitialiser remet tous les champs de saisie à blanc. Si le message ne parvient pas à être envoyé, un message apparaît immédiatement pour vous le notifier. De plus, si vous utilisez le paramétrage par défaut d’envoi d’emails dans O2S, vous disposez d’un rapport des envois d’email dans Services > Emails. rapport des envois d’email Services > Emails Notez que vous pouvez envoyer un mail à un contact, depuis votre liste de contacts, en cliquant sur à droite du contact puis sur Envoyer > Un email.
