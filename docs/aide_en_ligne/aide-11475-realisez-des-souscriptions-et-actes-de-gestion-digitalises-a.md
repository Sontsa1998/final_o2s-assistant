## Qu’est-ce qu’un partenaire Business Link ?

Un partenaire Business Link est un assureur ou une société de gestion connecté à O2S pour digitaliser vos actes de gestion (souscription, versement, arbitrage, rachat). Selon le partenaire, l’opération se fait directement dans O2S :. via une redirection vers l’extranet du partenaire où vous saisissez les informations. ou via la technologie Harvest Wealth Platform qui permet la transmission automatique de tout ou partie des données client (KYC, Allocation) vers le partenaire. ## Les 3 modes opératoires

Le mode disponible varie selon le partenaire et l’opération. Plus le mode est avancé, moins vous ressaisissez d’informations.

## Prérequis technique

Un code apporteur doit être paramétré dans O2S pour chaque partenaire concerné : Services > Administration > Gestion de l’agrégation > Source d’agrégation.

### Source d’agrégation

Si le partenaire n’est pas encore agrégé, demandez son agrégation via Nouvelle demande.
