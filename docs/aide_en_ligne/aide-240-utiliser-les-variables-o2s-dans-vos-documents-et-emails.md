O2S permet d’intégrer des variables dans les emails, lettres-types et documents basés sur des modèles Word. Ces variables personnalisent automatiquement certains champs, tels que le titre, le prénom ou le nom du destinataire, en récupérant les informations directement depuis les données d’O2S. Cela facilite la création rapide de mailings et publipostages personnalisés. Commençons par présenter toutes les variables disponibles, puis expliquons comment les intégrer dans les différents types de supports de courrier. Note : Les variables à intégrer dans vos modèles personnalisés de Déclaration d’Adéquation sont détaillées dans une rubrique d’aide dédiée qui vous permet de notamment prévisualiser le rendu des variables « projet » avant de les intégrer à votre déclaration d’adéquation.

### Liste des variables standards

Dans les documents créés dans O2S, depuis l’interface de rédaction de vos courriers, vous disposez d’une liste déroulante permettant d’insérer des variables. Elles sont classées par thèmes (commun, établissement, contact, personne morale, conjoint, conseiller, etc.). Pour insérer une variable, il suffit de placer le curseur de la souris à l’endroit où vous souhaitez l’insérer dans votre document, puis de cliquer sur la liste déroulante « Variables O2S » et de sélectionner la variable de votre choix. En cliquant sur l’intitulé de la variable dans la liste déroulante ci-dessus (qui correspond à la colonne de gauche du tableau ci-dessous), vous insérez le code (colonne de droite du tableau) correspondant dans le document.

Vous pouvez également insérer ces variables manuellement; dans ce cas, vous devez impérativement les saisir telles qu’elles apparaissent avec les 2 signes ‘$’, dans le tableau ci-dessous par exemple, vous devez saisir $CONTACT_SOCIETE$ si vous souhaitez insérer la variable Etablissement > Contact. ## Personne morale

Note : dans O2S, une personne morale est toujours considérée comme un « contact ». Pour renseigner correctement la raison sociale de la personne morale dans vos documents, nous vous invitons à utiliser la variable « Contact ». En effet, les variables liées à l’établissement reprennent les coordonnées de votre propre société, et non pas celles de la société cliente (personne morale). ## Insertion des variables

Dans O2S, ces variables peuvent être insérées dans trois types de supports : les emails, les lettres-types et les modèles Word. Cette section explique comment procéder.

## Insertion dans les emails

Depuis le module Requêtes, dans le tableau des résultats de vos requêtes, le menu (Actions) vous permet d’envoyer un message (Email > Envoyer un email) aux contacts contenus dans les résultats. Ceci est particulièrement pratique dans le cas où vous devez envoyer le même courrier à tous ces contacts, car les variables vous donnent la possibilité de personnaliser le courrier en fonction des informations portant sur chacun des contacts. La fenêtre qui s’ouvre vous permet de rédiger votre message. Si vous souhaitez personnaliser certaines données afin qu’elles soient automatiquement récupérées depuis O2S, il vous suffit d’insérer des variables dans le texte de votre message à l’aide de la liste déroulantes Variables O2S.

## Variables O2S

O2S récupère alors la valeur des variables correspondant à chacun de vos contacts et les substitue aux codes dans votre message. Chaque contact destinataire reçoit alors un email personnalisé avec ses données individuelles.

## Insertion dans les lettres types

Les lettres-types dans O2S peuvent être utilisées de différentes manières, notamment pour générer des impressions au format Word ou PDF. Dans le module Contacts > Liste des contacts, un clic droit sur un contact permet de choisir Imprimer > Un courrier (Word) ou Imprimer > Un courrier (PDF). Requêtes, dans le tableau des résultats d’une requête, il est également possible de cliquer sur le menu Actions puis sélectionner Imprimer > Un courrier (Word) ou Un courrier (PDF). A ce stade, vous avez la possibilité de modifier la lettre et d’y insérer des variables en cliquant sur le bouton. lettre type La fenêtre de configuration de la lettre type s’ouvre alors. O2S », vous pouvez modifier ou insérer les variables de votre choix.

La procédure est identique lorsque vous souhaitez insérer des variables dans une nouvelle lettre-type.

## Insertion dans les modèles Word

Pour créer une lettre-type entièrement personnalisée, il est possible d’utiliser le logiciel Word. O2S permet ensuite d’exploiter ce modèle pour l’envoi des courriers.

### Création du modèle dans Word

Il suffit de rédiger la lettre dans Word, d’y insérer des images et de profiter de toutes les fonctionnalités de mise en page offertes par le logiciel pour soigner la présentation du document. L’insertion des variables se fait en les saisissant manuellement aux emplacements souhaités dans le document. Attention Les variables $PRENOM_NOM_DATE_NAISSANCE_ENFANT$ et $TITRE_PRENOM_NOM_REPRESENTANT$, ainsi que toutes les variables débutant par $LISTE_ … génèrent une liste (puces), et doivent donc figurer seules sur une ligne après un saut de ligne. Vous devez adapter votre document ou mail en insérant un saut de ligne avant ces variables afin de garantir une mise en forme correcte. De même, vous devez impérativement les insérer entre 2 signes ‘$’.

Veillez bien à ne pas saisir d’espace au sein du code de la variable. Nous vous conseillons de copier-coller ces codes depuis le tableau des variables. Enregistrez ensuite votre document au type « Document Word » (ce qui lui donnera l’extension.docx), à l’emplacement de votre choix.

### Utilisation dans O2S

Liste des contacts, en effectuant un clic droit sur un contact, sélectionnez Imprimer > Un courrier à partir d’un modèle (Word). Faites glisser le document « modèle » que vous avez créé sur la zone délimitée par des pointillés. Le document est alors chargé afin d’être utilisé pour votre envoi de courrier. OK, les variables sont remplacées par les valeurs correspondant au contact destinataire du courrier et le document final s’ouvre à l’écran. Toute variable mal orthographiée ou bien non comprise entre deux sigles ‘$’ ne sera pas interprétée. Dans ce cas, le code de la variable figurera dans la lettre.

### Note sur le rendu des variables dans les modèles

La taille et la police du contenu sont reprises directement depuis le modèle Word et appliquées à la variable déclarée. lorsque les variables sont remplacées par un tableau, les éléments de mise en forme (couleur du tableau, présence ou non des bordures, couleur des bordures……) dépendent du thème sélectionné dans le module Services > Éditions > Générales (1/2) > Les thèmes des éditions.
