Fiche d'agrégation du partenaire **Gresham Banque** dans O2S.

#### À savoir

Vous devez completer et signer le formulaire d'abonnement Gresham. Votre code apporteur est composé de 5 chiffres correspondant au code selligent chez Gresham Banque - Intencial. Tous les mouvements depuis l'ouverture des contrats peuvent être agrégés

#### Produits agrégés

Altizen 2, Altizen 2 Capi, FPCI Novaxia Immo Evolution, FPCI Novaxia Immo Evolution 2, Novaxia Immo Opportunité 6, Intencial Initiative PEA, Skandia Gestion Privée 2, Skandia Gestion Privée Capi 2, Xo Vie (Apicil Invest)

#### Prix d'achat moyen

Les prix d'achat moyens sont transmis par ce fournisseur.

Hors Nomenclature, OST avec impact fiscal, Vente de titres, Entrée d'espèces, Frais de gestion, Sortie d'espèces, OST sans impact fiscal, Distribution de revenus (coupons, SCPI), Achat de titres, Transfert sortant, Transfert entrant
