Vous pouvez personnaliser la déclaration d’adéquation selon vos souhaits en y insérant les variables présentées ci-dessous. ATTENTION ! Vous devez impérativement les saisir telles qu’elles apparaissent avec les 2 signes ‘$’, dans les tableaux ci-dessous. Nous vous conseillons de les copier depuis la présente page, puis de les coller dans votre document modèle Word de Déclaration d’adéquation. Par exemple, vous devez saisir $PROJET_CLASSIFICATION_CLIENT_MIF$ si vous souhaitez insérer les données correspondant à la variable Classification MIF retenue.
