Préambule. Disposez d’une navigation simplifiée et sécurisée entre O2S et l’extranet de Suravenir. Après une 1ère et unique authentification, vous pourrez accéder aux comptes de Suravenir, mettre à jour les informations sur les clients, ou réaliser des transactions sur ces mêmes comptes (proposition d’arbitrage, arbitrage, …) dans l’extranet sans avoir à vous identifier à nouveau. Vous disposez automatiquement de ce nouveau service mais lors de la première utilisation, vous devrez saisir vos codes d’accès à l’extranet SURAVENIR. Par la suite cette identification ne sera plus nécessaire. Si vous ne pouvez pas accéder au service, vous pouvez contacter l’assistance O2S au 01.55.82.07.08. Si vous ne disposez pas de vos codes d’accès à l’extranet SURAVENIR, nous vous invitons à vous rapprocher de Suravenir.

Si vous disposez de plusieurs codes d’accès, consultez le paragraphe dédié . Accès au compte,transactions et données client. Un accès depuis la liste des portefeuilles. Dans O2S, allez dans le module Contacts > Portefeuille afin d’afficher le compte Suravenir auquel vous souhaitez accéder. Cliquez sur le bouton Réaliser un acte : Dans O2S, allez dans le module Contacts > Portefeuille afin d’afficher le compte Suravenir auquel vous souhaitez accéder. Au cas où rien ne se passe après avoir cliqué sur l’icône, le bloqueur pop-up de votre navigateur a probablement empêché l’extranet de s’ouvrir. Dans ce cas, cherchez dans l’angle supérieur droit de votre navigateur une icône ou un message qui indiquent le blocage.

Cliquez dessus et acceptez les popups de manière générale ou créez une exception pour le site Oriadys. S’il s’agit de votre 1er accès à l’extranet depuis O2S ou si votre 1ère connexion date de plus de 6 mois, vos codes d’accès vous sont demandés : Si vous disposez de plusieurs logins d’accès SURAVENIR, vous devez utiliser le login qui vous permet habituellement de visualiser ce même contrat sur l’extranet ORIADYS. Ensuite, O2S interroge l’extranet de Suravenir pour connaitre la liste des actions qui sont accessibles sur ce compte. Sélectionnez le type d’action que vous souhaitez effectuer. Enfin, vous accédez directement à l’extranet de Suravenir. L’accès depuis la liste des comptes est possible en cliquant sur l’icône (business link) : Un accès depuis les transactions.

Suravenir sur lequel vous souhaitez réaliser une transaction. Cliquez sur l’icône : Dans la page qui s’ouvre, cliquez sur l’onglet Transactions puis sur Ajouter. Suite à cette sélection, O2S interroge l’extranet de Suravenir pour connaitre la liste des transactions qui sont accessibles sur ce compte. O2S affichera la liste des actes de gestion permis sur l’extranet de Suravenir. Ceux auxquels vous n’avez pas accès sur ce compte seront affichés grisés et non cliquables. Suite à cette sélection, vous basculez automatiquement sur le même compte sur l’extranet de Suravenir. Il ne vous reste plus alors qu’à effectuer votre transaction et à la valider. ### Mise à jour des données client

Une page permet de consulter les informations de votre client afin de relever les données manquantes et de les compléter, le cas échéant. Pour ce faire, cliquez sur l’icône et sur le choix Mise à jour client. Puis cliquez sur OK. La page Complétude des données s’ouvre. Vous retrouvez ici toutes les informations essentielles sur votre client. OK Complétude des données Pour une adresse française, le code INSEE commune doit être saisi, de ce fait les champs Code postal et Ville sont automatiquement alimentés. Pour une adresse étrangère, vous devez saisir le code postal et la ville. Lorsque vous avez terminé la modification des données de votre choix, cliquez sur Mettre à jour; les données sont alors mises à jour dans la base Suravenir ainsi que dans votre base O2S.

Certaines données ne sont pas mises à jour dans O2S (les objectifs et la notion de PPE); leur mise à jour n’est donc effectuée que dans la base Suravenir uniquement. Suravenir, vous devez utiliser celui qui vous permet habituellement de visualiser le contrat sur l’extranet ORIADYS. Si la visualisation de certains contrats Suravenir n’est pas autorisée pour ce login, une nouvelle authentification vous sera proposée : Attention à ne pas saisir le login Primonial / ORIADYS. En cas d’erreur, vous pouvez vous connecter avec un autre login en cliquant sur Utiliser un autre login de connexion. Une fois la transaction validée sur Suravenir, celui-ci informe O2S de l’état d’avancement de la transaction.
