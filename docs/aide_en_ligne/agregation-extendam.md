Fiche d'agrégation du partenaire **Extendam** dans O2S.

#### À savoir

Vous devez envoyer les fichiers de vos données depuis votre extranet d'ExtendAM. Votre code apporteur est composé d'une série de chiffres et de lettres que vous pouvez retrouver sur l'extranet.

#### Produits agrégés

Extend Nominatif Pur, Mandat de Gestion (Extendam), OTC Investissement PME, Souscription Libre (Extendam)

#### Prix d'achat moyen

Les prix d'achat moyens ne sont pas transmis par ce fournisseur.

#### Fréquence d'agrégation

La fréquence d'agrégation est hebdomadaire
