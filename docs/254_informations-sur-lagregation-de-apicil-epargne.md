# Apicil Epargne

## À savoir
Vous devez compléter le formulaire d'abonnement faisant office de lettre d'autorisation de transfert de données vers Harvest.

Votre code apporteur est composé de 4 chiffres ou 5 chiffres (10...), correspondant au code sunshine chez Apicil Intencial
Tous les mouvements depuis l'ouverture des contrats peuvent être agrégés
