## 146. Utiliser les variables O2S dans vos documents et emails

O2S permet d’intégrer des variables dans les emails, lettres-types et documents basés sur des modèles Word. Ces variables personnalisent automatiquement certains champs, tels que le titre, le prénom ou le nom du destinataire, en récupérant les informations directement depuis les données d’O2S. Cela facilite la création rapide de mailings et publipostages personnalisés.  Commençons par présenter toutes les variables disponibles, puis expliquons comment les intégrer dans les différents types de supports de courrier. Insertion des variables Dans O2S, ces variables peuvent être insérées dans trois types de supports : les emails, les lettres-types et les modèles Word. Cette section explique comment procéder. Insertion dans les emails. Insertion dans les emails Depuis le module Requêtes , dans le tableau des résultats de vos requêtes, le menu  (Actions) vous permet d’envoyer un message ( Email > Envoyer un email ) aux contacts contenus dans les résultats. Ceci est particulièrement pratique dans le cas où vous devez envoyer le même courrier à tous ces contacts, car les variables vous donnent la possibilité de personnaliser le courrier en fonction des informations portant sur chacun des contacts. Requêtes Email > Envoyer un email La fenêtre qui s’ouvre vous permet de rédiger votre message. Si vous souhaitez personnaliser certaines données afin qu’elles soient automatiquement récupérées depuis O2S, il vous suffit d’insérer des variables dans le texte de votre message à l’aide de la liste déroulantes Variables O2S . Variables O2S  O2S récupère alors la valeur des variables correspondant à chacun de vos contacts et les substitue aux codes dans votre message. Chaque contact destinataire reçoit alors un email personnalisé avec ses données individuelles. Insertion dans les lettres types. Insertion dans les lettres types Les lettres-types dans O2S peuvent être utilisées de différentes manières, notamment pour générer des impressions au format Word ou PDF. Depuis le module Requêtes , dans le tableau des résultats d’une requête, il est également possible de cliquer sur le menu Actions puis sélectionner Imprimer > Un courrier (Word) ou Un courrier (PDF) . Dans le module Contacts > Liste des contacts , un clic droit sur un contact permet de choisir Imprimer > Un courrier (Word) ou Imprimer > Un courrier (PDF) . Insertion dans les modèles Word Pour créer une lettre-type entièrement personnalisée, il est possible d’utiliser le logiciel Word. O2S permet ensuite d’exploiter ce modèle pour l’envoi des courriers. Création du modèle dans Word. Il suffit de rédiger la lettre dans Word, d’y insérer des images et de profiter de toutes les fonctionnalités de mise en page offertes par le logiciel pour soigner la présentation du document. Contacts > Liste des contacts Imprimer > Un courrier à partir d’un modèle (Word) Faites glisser le document « modèle » que vous avez créé sur la zone délimitée par des pointillés.  Le document est alors chargé afin d’être utilisé pour votre envoi de courrier. En cliquant sur OK , les variables sont remplacées par les valeurs correspondant au contact destinataire du courrier et le document final s’ouvre à l’écran. OK  Attention ! Toute variable mal orthographiée ou bien non comprise entre deux sigles ‘`$`’ ne sera pas interprétée. Dans ce cas, le code de la variable figurera dans la lettre. Attention !  Note sur le rendu des variables dans les modèles Word La taille et la police du contenu sont reprises directement depuis le modèle Word et appliquées à la variable déclarée. lorsque les variables sont remplacées par un tableau, les éléments de mise en forme (couleur du tableau, présence ou non des bordures, couleur des bordures……) dépendent du thème sélectionné dans le module Services > Éditions > Générales (1/2) > Les thèmes des éditions .
