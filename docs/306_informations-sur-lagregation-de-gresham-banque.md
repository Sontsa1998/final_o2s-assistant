# Gresham Banque

## À savoir
Vous devez completer et signer le formulaire d'abonnement Gresham.

Votre code apporteur est composé de 5 chiffres correspondant au code selligent chez Gresham Banque - Intencial.
Tous les mouvements depuis l'ouverture des contrats peuvent être agrégés
