## 158. Immobilier

La gestion des biens immobiliers s’effectue dans l’espace Autres > Immobilier du module Contacts de votre client. Celui-ci se compose d’un tableau récapitulatif du patrimoine immobilier du contact et de 3 onglets disposant d’actions définies : Autres > Immobilier Contacts L’onglet Prêt n’apparaît que si vous avez défini un prêt pour le bien immobilier. L’onglet Epargne n’apparaît que si vous avez défini un adossement pour le prêt. Prêt Epargne Volet / Zone Informations Immobilier Dans cet onglet, renseignez les informations afférentes au bien immobilier (adresse, mode d’acquisition, etc.). Acquisition Vous pouvez renseigner ici les informations concernant la promotion, la gestion, le notaire et l’expert-comptable du bien immobilier. Pour chacun des intervenants vous pouvez définir et gérer un ensemble de listes vous permettant d’éviter de futures saisies superflues dans le cas où vous travaillez régulièrement avec les mêmes intervenants. Prêt En effectuant un clic droit sur un bien immobilier puis en choisissant Ajouter prêt, vous pouvez accéder à différentes actions indiquées ci-dessous : Note : dans l’onglet Immobilier , si vous cliquez sur le bouton-radio Oui de ‘Financement à crédit’, l’onglet Prêt apparaît automatiquement. Modifier le prêt Ajustez si besoin les informations initialement saisies sur le prêt. Supprimer le prêt Supprimez définitivement le prêt. Ajouter un adossement : Note : pour ajouter un adossement, le mode de remboursement du prêt doit être « in-fine » Pour ajouter un adossement, sélectionnez la ligne du prêt dans l’onglet Financement . Cliquez avec le bouton droit sur Ajouter adossement , saisissez ensuite les informations relatives à l’adossement sur la base du contrat d’assurance vie adossé. Cliquez sur Enregistrer . Modifier le compte de prélèvement Pour spécifier le compte de prélèvement, faites un clic droit sur la ligne du prêt en question puis cliquez sur le bouton Modifier l’assurance du prêt . Ce compte comporte les coordonnées bancaires du client, et permet d’effectuer le prélèvement des échéances. Ajouter / Modifier l’assurance du prêt Cliquez sur le bouton Modifier l’assurance du prêt pour ajouter/modifier une assurance à un prêt. Modifier l’établissement prêteur Il s’agit des cordonnées de la banque prêteuse (nom, adresse, tel). Pour modifier ces informations, il suffit de cliquer sur Modifier l’établissement prêteur . Export Produisez un document au format PDF ou Excel. Epargne Modifier l’adossement Ajustez si nécessaire les informations saisies initialement sur l’adossement concernant le prêt. Supprimer l’adossement Supprimez définitivement l’adossement. Ajouter un versement exceptionnel / périodique Pour ajouter un nouveau versement, sélectionnez l’onglet Epargne après avoir choisi le prêt puis cliquez avec le bouton droit sur Ajouter un versement . Saisissez les champs de cette fenêtre puis enregistrez les informations pour ajouter le versement. Volet / Zone	Informations
