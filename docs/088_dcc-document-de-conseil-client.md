## 88. DCC (Document de Conseil Client)

Le DCC est un document qui synthétise les informations clés sur votre client : situation familiale, patrimoine, fiscalité, revenus et objectifs. Il peut être généré pour : DCC Les personnes physiques : un modèle standard est disponible par défaut dans O2S. Les personnes morales : un modèle spécifique doit être créé à l’aide d’un document Word. Les personnes physiques : un modèle standard est disponible par défaut dans O2S. Étape 1 : Créer un modèle Word DCC Préparez un document Word contenant le texte et les variables O2S nécessaires (https://o2s-help.harvest.fr/utiliser-les-variables-o2s-dans-vos-mails-et-lettres/) . Notez que vous pouvez utiliser les variables de votre choix, dont celles qui concernent spécifiquement les personnes morales (https://o2s-help.harvest.fr/utiliser-les-variables-o2s-dans-vos-mails-et-lettres/#personne_morale) . Accédez à Services > Personnalisation > Modèles Word > Modèles Word . Cliquez sur Ajouter un modèle . Importez votre document Word en le glissant-déposant dans la zone en pointillés ou en cliquant pour le sélectionner. Donnez un nom explicite à votre modèle dans le champ Nom retenu (ex. : DCC Personne Morale ). Une fois créé, le modèle apparaît dans la liste des modèles Word disponibles. Étape 2 : Générer le DCC Dans le module Contacts , cliquez sur le bouton (3 points) à droite de la ligne de la personne morale concernée. Sélectionnez Imprimer > Un courrier à partir de la bibliothèque Word . Dans la fenêtre d’impression, choisissez le modèle Word DCC Personne Morale que vous avez créé. Cliquez sur OK . Le DCC personnalisé est généré et disponible dans le dossier de téléchargement de votre navigateur.
