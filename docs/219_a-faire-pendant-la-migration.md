## 219. A FAIRE PENDANT LA MIGRATION

1. Préparer dans O2S le MoneyPitch de votre client Nexus (ne concerne pas les cabinets possédant déjà un O2S). 1. Préparer dans O2S le MoneyPitch de votre client Nexus > Pour que votre client retrouve dans la GED MoneyPitch les documents provenant de sa GED Nexus. Vous devez suivre la procédure de copie des documents (https://o2s-help.harvest.fr/ged-moneypitch/) en copiant les documents concernés dans le dossier "O2S - MoneyPitch" . "O2S - MoneyPitch" > Pour que votre client puisse voir dans MoneyPitch les comptes de ses relations. Par défaut, la visibilité des comptes des relations (dont le conjoint) dans MoneyPitch est désactivée. Pour les rendre visibles, vous devez suivre ces étapes simples (https://o2s-help.harvest.fr/afficher-les-comptes-du-conjoint-du-client-dans-moneypitch/) .   2. Suivre l'avancement de vos demandes d'agrégation dans O2S. 2. Suivre l'avancement de vos demandes d'agrégation dans O2S Si vous êtes administrateur d'O2S, depuis le module d'administration (accessible via votre menu utilisateur en haut à droite > Administration > Gestion de l'agrégation > onglet Gestion de l'agrégation ), vous pouvez suivre l'état d'avancement de vos demandes d'agrégation de vos partenaires. Pour chaque source d'intégration, dans la colonne Statut : menu utilisateur > Administration > Gestion de l'agrégation > Gestion de l'agrégation  Statut Si [icone : point d'interrogation dans cercle noir] est affiché : la demande d'agrégation du partenaire est en cours de traitement Si [icone : coche verte] est affiché : l'agrégation du partenaire dans O2S est OK Si [icone : point d'interrogation dans cercle noir] est affiché : la demande d'agrégation du partenaire est en cours de traitement Si [icone : coche verte] est affiché : l'agrégation du partenaire dans O2S est OK  Situations de comptes Situations de comptes Pendant le processus de bascule, en fonction de la réactivité de votre partenaire, il est possible que les situations des comptes de vos clients ne se mettent pas à jour pendant quelques jours. Néanmoins, lorsque votre partenaire commencera à envoyer les données vers O2S, et que la reprise de l’agrégation se fera côté O2S, les mouvements seront envoyés rétro-activement et il n’y aura pas de perte de données. Les comptes et leur historique sont repris dans O2S.  Note sur l'Accessibilité de Prisme pendant la migration. Note sur l'Accessibilité de Prisme pendant la migration Prisme restera accessible pendant environ 3 mois, mais à J-1 de l’ouverture d’O2S, nous vous invitons à ne plus saisir ces catégories de données dans Prisme car elles ne seront pas synchronisées avec O2S. Avec Prisme en lecture seule, Prisme fonctionnera "normalement", c'est à dire que vous pourrez toujours effectuer des sauvegardes, extraire des données, utiliser le module de requêtes, etc...  NOTE NOTE NOTE Une fois que vous disposez d'O2S, pour trouver efficacement des informations sur l'utilisation et le paramétrage d'O2S, utilisez l' Assistant Aide IA accessible en bas à droite d'O2S via un bouton orange : posez-lui vos questions en langage naturel, tout en lui indiquant que vous utilisiez Prisme auparavant.
