## 383. Prix d'achat moyen

Prix d'achat moyen


1. Connaissance


1.1 : Description

Le prix d'achat moyen est une donnée pouvant être agrégée afin de produire des calculs de performance (plus-value, moins-value) sur chacune des lignes sur lesquelles le contrat est investi. En effet, le prix d'achat moyen est associé à un support. Toutefois, il est à noter que cette donnée n'est pas proposé par toutes les sources d'agrégation ni pour tous les supports. C'est donc une donnée optionnelle, mais dont l'absence ou la mauvaise valorisation est pénalisante pour l'utilisateur lorsque la source d'agrégation s'était engagée à la fournir.
Fournir à l'utilisateur une explication claise des raisons pour lesquelles un prix d'achat moyen ne serait pas présent ou erroné. Guider l'utilisateur à travers les étapes de vérification qu'il peut effectuer lui-même. Si le problème persiste après les vérifications initiales, proposer de soumettre le cas à l'équipe technique. Demander l'autorisation de faire suivre la conversation à l'assistance pour éviter une double saisie. Collecter les informations nécessaires pour l'escalade à une équipe technique.

1.2 Méthode


Hypothèse : Certaines sources d'agrégation ne fournissent pas les prix d'achat moyen, ou pas sur tous les supports.
Action : Vérifier dans la documentation si la source d'agrégation concernée met à disposition leles prix d'achat moyen.

Hypothèse : Des problèmes peuvent affecter temporairement l'agrégation ou la valorisation des prix d'achat moyen. Les incidents en cours sont signalés sur cette page : https://o2s-help.harvest.fr/meteo-agregation/
Action : Vérifier les incidents en cours liés à la source d'agrégation. Un incident peut influer sur la valorisation ou l'actualisation de prix d'achat moyen.

2. Glossaire


Terme : Prix d'achat moyen
Synonymes : Prix moyen d'achat, PAM, PMA, PAMP, PMAP, prix d'achat moyen pondéré
